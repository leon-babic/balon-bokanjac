# Nedjeljna liga – Balon Bokanjac ⚽

Stranica za nedjeljni nogomet u balonu na Bokanjcu: kartice igrača s posebnim animacijama, tablica sezone, Zlatna kopačka, slaganje ekipa i rezultati utakmica.

Napravio: **Leon Babić**

## Tehnologije

- [React](https://react.dev) + [Vite](https://vite.dev)
- [Motion](https://motion.dev) za animacije
- GitHub Pages (automatska objava preko GitHub Actions)

## Pokretanje

```bash
npm install
npm run dev
```

Podaci (igrači, utakmice) su u `src/data.js`.
